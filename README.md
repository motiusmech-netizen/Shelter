# Атомное Убежище

Мобильная HTML5-игра для Яндекс Игр в духе Fallout Shelter: вы — смотритель подземного убежища.
Всё в одном файле, без внешних зависимостей — графика рисуется на canvas, звук синтезируется через WebAudio,
шрифты встроены.

## Что есть в игре

- **Главное меню**: новое убежище (свой номер), продолжить, справка, звук.
- **Строительство**: 22 типа комнат + лифты. Комнаты ставятся рядом с другими комнатами или лифтом,
  новые этажи копаются лифтом вниз. Одинаковые соседние комнаты одного уровня сливаются (до 3 секций),
  улучшение до 3 уровня, снос. Новые комнаты открываются с ростом населения (как в оригинале: склад с 12,
  медпункт с 14, …, завод Атом-колы со 100 жителей).
- **Ресурсы**: энергия, еда, вода, крышки, Атом-кола, аптечки, антирадин. Сбор готовой продукции нажатием.
  При нехватке энергии гаснут самые дальние от электростанций комнаты, без еды жители теряют здоровье,
  без воды — облучаются.
- **Жители**: 7 характеристик (СИЛ, ВОС, ВЫН, ХАР, ИНТ, ЛОВ, УДА), уровни и опыт, здоровье и радиация,
  счастье (выше, когда работают по призванию), оружие и одежда с бонусами, переименование, изгнание.
- **Новые жители**: выжившие приходят к двери — впустить или прогнать; Радиостудия привлекает новых;
  редкие и легендарные жители из ящиков снабжения.
- **Дети**: мужчина и женщина в жилых помещениях знакомятся, танцуют — появляется ребёнок,
  который вырастает в нового работника. Родственники пар не образуют.
- **Тренировки**: 7 тренировочных залов поднимают характеристики до 10.
- **Ускорение** комнат с риском: пожар, тараканы-мутанты, мутокрысы, радскорпион.
- **Набеги**: рейдеры, дикие гули, когтистые твари. Дверь с прочностью и улучшениями, охрана у двери,
  враги идут по убежищу из комнаты в комнату и крадут крышки. Погибших можно воскресить.
- **Пустошь**: поход с аптечками и антирадином, журнал событий, бои, крышки, хлам и снаряжение;
  возвращение занимает половину времени похода.
- **Задания смотрителя**: отряды до 3 жителей, шанс успеха по силе отряда, награды.
- **Крафт** оружия и одежды из хлама; уровень мастерской открывает редкие и легендарные вещи.
- **Цели** с наградами, **ящики снабжения** с 4 картами, **роботы-помощники** собирают ресурсы на этаже.
- **Офлайн-прогресс** до 2 часов, автосохранение.
- **Обучение** для первых шагов.

## Яндекс Игры

- SDK подключается из `/sdk.js`: `LoadingAPI.ready()`, `GameplayAPI.start/stop`, пауза по
  `game_api_pause/resume`, облачные сохранения через `player.setData/getData`,
  полноэкранная реклама при входе в игру, реклама за награду (ящик снабжения, воскрешение).
- Звук и игра ставятся на паузу во время рекламы и при сворачивании вкладки.
- Вне Яндекс Игр игра работает автономно: сохранение в `localStorage`, реклама пропускается.
- Названия и бренды Fallout не используются (своё название, валюта «Атом-кола», свои имена врагов),
  чтобы игра прошла модерацию.

## Сборка

```bash
node tools/build.mjs
```

Результат:

- `dist/atom-shelter-yandex.zip` — архив для загрузки в консоль разработчика Яндекс Игр;
- `dist/yandex/index.html` — тот же файл без архива;
- `dist/artifact.html` — фрагмент для веб-предпросмотра.

Исходники — в `src/` (`js/` по модулям, `style.css`, `body.html`, `fonts/` — Russo One и PT Sans Narrow, лицензия OFL).
